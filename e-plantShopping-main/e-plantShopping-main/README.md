# e-plantShopping

e-plantShopping is a React-based online plant shopping application for a fictional store called Paradise Nursery.

## Features

- Landing page with a "Get Started" button
- Plants page listing available plants, with an option to add each one to the cart
- Shopping cart page to view, update and remove items
- Navigation bar with links to the landing page, the plants page and the cart

## Tech Stack

- React
- Redux Toolkit for cart state management
- JavaScript, HTML and CSS
